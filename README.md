# A Lightweight Adversarial Hardening and Federated Learning based Framework for IoT Malware Detection
A framework for detecting malware files in IoT edge devices, built by integrating adversarial hardening and federated learning


# Extraction
To extract the benign executables run the following command from this directory 

```
pip install -r requirements.txt
python pipelines/tabular/extract_ipk.py
python pipelines/assembly/extract_assembly.py
```
